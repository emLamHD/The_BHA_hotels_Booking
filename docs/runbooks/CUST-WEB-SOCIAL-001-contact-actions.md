# Configure Customer contact actions

Open Admin → Website → Social media. Changes are a draft until **Lưu**; **Huỷ** restores the last confirmed database state.

- Messenger: find the Facebook Page's real username/chat destination, form `https://m.me/<username-cua-trang>` (do not use the display name or Facebook home), paste it, open the preview/link yourself, then enable and save.
- Zalo: enter the Vietnamese number actually linked to the account that should receive contacts, open the generated `https://zalo.me/<number>` preview yourself, then enable and save.

The application validates link shape only. It does not prove that an external account exists or belongs to The BHA. Until Owner supplies and verifies these destinations, Messenger and Zalo remain off. A Customer request sees a confirmed Save immediately; an already-open visible tab refreshes within 15 seconds. If a Save loses its response, use the screen's server check before sending again.
