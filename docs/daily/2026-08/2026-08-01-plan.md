## 6. Main risks and mitigations

| Risk | Mitigation |
|---|---|
| Hai agent cùng hoạt động | manual active-agent gate + process stop evidence |
| Prompt conflict | RULES/AGENTS authoritative; review skill trước khi cài |
| Tool tự tạo worktree/agent | tắt auto-routing/parallel; dry run read-only |
| Token tăng do hai agent đọc trùng | shared prompt ngắn, READ_NOW theo phase, worklog on-demand |
| Handoff mất context | Git checkpoint + structured phase report |
| Repo bị bẩn trong setup | cài ngoài product source; kiểm tra `git status` ở mỗi gate |
| Quyền merge bị rò | Owner-only rule; disable automation push/merge |
| FE-002.1 mở sớm | Snapshot và plan giữ explicit lock đến Owner decision |

## 7. Rollback criteria

Rollback hoặc disable capability mới nếu:

- không thể ngăn parallel execution;
- công cụ sửa repo/config ngoài phạm vi không minh bạch;
- telemetry/privacy không thể cấu hình ở mức Owner chấp nhận;
- shared instruction bị tool override;
- GitNexus hoặc test/dev workflow hiện tại bị phá;
- chi phí vận hành/handoff lớn hơn lợi ích trong pilot.

Rollback phải đưa repo về clean baseline và không ảnh hưởng `develop`.
